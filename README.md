# Object-Oriented Programming (OOP) Labs

Welcome to my Object-Oriented Programming (OOP) Lab repository! This repository contains a structured collection of labs completed during my OOP course, focusing on mastering core object-oriented design and programming principles in C++.

## 🚀 Key Concepts Covered

* **Core OOP Pillars:** Classes & Objects, Encapsulation, Abstraction, Inheritance, and Polymorphism.
* **Data Structures & Memory:** Stack implementation, custom dynamic structures (Bag class), Pointers, Dynamic Arrays, and Jagged 2D Arrays.
* **Advanced Features:** Operator Overloading, Complex Class Hierarchies, and File Handling (Sequential and Random Access I/O).

---

## 📂 Repository Structure

The repository is organized by weekly lab sessions, moving from foundational syntax to advanced object-oriented architectures:

| Directory | Description |
| :--- | :--- |

| **Lab 15** | C++ File Handling implementing Sequential and Random Access I/O. |

*Note: Missing lab sequences indicate specific evaluation/quiz weeks or mid-term breaks.*
